# Arrival outcome

Guests must be able to understand whether payment is pending and obtain access once the server confirms eligibility. Prevent duplicate payment attempts. The browser is one step in this journey: Stay, hosted checkout, bank challenge, return, server status, access.

Support notes show that returning guests often still have a pending checkout. They need a clear processing state and recovery of that checkout. Closing a page is not a confirmed payment. The accepted scope reuses hosted checkout; native payment forms are outside this task.
