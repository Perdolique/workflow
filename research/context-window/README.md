# Codex context-window research

This public archive preserves aggregate results and decisions from repeated studies of programming, analytics, and research sessions. It is enough to continue the investigation after pulling this repository on another computer. It does not contain private session records.

| File | Purpose |
| --- | --- |
| [Current assessment](current.md) | Latest recommendation, observed settings, and open questions |
| [Study history](history.md) | Earlier results, recommendations, and corrections |
| [Aggregate results](results.json) | Dated metrics, selection methods, and coverage boundaries |
| [Update procedure](update.md) | How to add new local work without repeating all earlier research |

After `git pull`, ask the agent to supplement or update this research. The repository instructions direct it here. It will inspect the local history, add a dated result, and update the assessment. No ZIP, private source archive, or old chat attachment is required.

The archive stores conclusions and coverage, not a list of analyzed session IDs. A new computer receives its own anonymous corpus label. Results from different computers or overlapping periods remain separate unless their overlap is checked locally. Exact session deduplication and new rolling-window percentiles cannot be recovered from aggregate numbers alone.
