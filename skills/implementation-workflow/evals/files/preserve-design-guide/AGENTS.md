# Repository instructions

- Use `vp` for local package commands.
- Before changing UI, styling, themes, or responsive behavior, read `apps/web/DESIGN.md` and inspect the relevant images in `apps/web/designs`. Images govern visual composition; update conflicting written guidance. Keep accessibility and delivered behavior, and omit unsupported controls.
- Keep Markdown paragraphs on one source line. Run focused checks for changed files; Markdown changes use `vp run lint:markdown`.
