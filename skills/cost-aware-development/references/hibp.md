# HIBP cost reference

Last verified: 2026-08-24.

## Pwned Passwords

- The Pwned Passwords range API is free and requires no subscription key.
- Do not infer that other HIBP APIs are free. Email-address, domain, and other subscriber endpoints may require a paid plan and an API key.
- Source: [Have I Been Pwned API documentation](https://haveibeenpwned.com/API/v3#PwnedPasswords).

When a task only checks password hashes through the Pwned Passwords range API, do not propose a paid HIBP subscription as a cost-control requirement.
