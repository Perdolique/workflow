# Approved repository setup design

This designer specification is final.

- Keep the page in one column.
- Keep the title, intro, five sections, headings, paragraphs, and section order exactly as written in `content-hierarchy.html`.
- Give all five sections a white surface, a `1px solid var(--border)` border, an `8px` corner radius, `24px` padding, and `24px` vertical spacing.
- Keep every section expanded on the page. Do not use tabs, disclosures, or dialogs.
- Give the Connect repository button a `1px solid var(--accent)` border, an `8px` corner radius, `10px 16px` padding, white text, and an accent background. Use the accent color nowhere else.
- Do not add visible icons, illustrations, or other graphics.
