Read-only access

The service requests read-only access to repository contents. It cannot push commits or change repository settings.

Advanced matching rules

The advanced matching rules section contains advanced matching rules that control which repository paths are included.

Rules use glob patterns. Later rules override earlier rules. A leading exclamation mark excludes a path.

Troubleshooting

The troubleshooting section provides troubleshooting information for repository connections.

If the repository does not appear, check that the integration has access to its organization and reload the repository list.
