# Specialist instructions

- Read the assigned role checklists. Delegate one coherent responsibility per child when a role calls for it. Mark the child assignment as internal. Use the [launch rules](launch.md) and give the child the [child instructions](child-review.md) and its assigned checklist. Keep the specialist's role and delegation instructions with the parent. Check child evidence before combining findings.
- Combine findings with the same root cause before validation and assign each candidate a stable ID. Keep every supported candidate, including low-priority, cosmetic, and readability findings.
- If candidates exist, use the [launch rules](launch.md) to start exactly one fresh internal [final finding validator](validation.md) for the combined list. Pass the exact candidate list with IDs and any proposed fixes, relevant code scope, and prior evidence and reproduction results. If the list is empty, report the checked scope and open items.
- Return each candidate's decision, evidence, proposed fixes, and any fix assessments under its ID. Report completed scope and open items using [Review results](results.md).
