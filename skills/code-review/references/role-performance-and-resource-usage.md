# Performance and resource usage

Review performance under supported workloads.

- Check how runtime and memory use grow with the workload. Look for avoidable work in the algorithm.
- Check cache behavior, including avoidable work on misses. Check how resources are used and released.
- Check how quickly the interface responds during interactions on supported devices and input methods.
- Check for stutter during interactions, animations, and transitions. Look for motion that blocks available actions.
