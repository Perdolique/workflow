# Review results

- Report checked scope and confirmed findings. Use `No issues found.` exactly when the assigned scope is complete and has no findings or open items.
- Use `Incomplete review` for unfinished technical checks, including work blocked by missing evidence or expertise.
- Use `Human review` for a material decision or confirmation that requires unavailable project knowledge from a person.
- Keep an unresolved candidate's ID and status. Report each open item once in the matching section. Give its location or affected scope, what is missing, why it matters, and what would resolve it.
