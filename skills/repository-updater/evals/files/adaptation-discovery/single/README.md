# Local handbook

This repository renders one small handbook in English. There are no other build targets, diagrams, custom extensions, or deployment services. `./build.sh` runs once per edit and writes `site/en`.

The current Docforge pin is 2.8.0. The ordinary and zero-maturity discovery results both contain only Docforge 3.0.0. The update policy permits this target.

The latest measured build took 0.08 seconds: 0.04 seconds to parse and load the theme, and 0.04 seconds to render HTML. It ran one process and read the source tree once.
