# Routing comparison

## Version A

- Use the standard reviewer for every assignment.
- Return the reviewer's findings.

## Version B

- Choose a reviewer for each focused assignment.
- Use the standard reviewer for ordinary work. Use the expert reviewer when available evidence supports competing explanations across interacting contracts.
- Record the reasoning difficulty that supports each expert assignment.
- There is no fixed expert-reviewer limit per review.
- Return the reviewers' findings and routing decisions.

## Recorded executions

Both versions received the same two independent protocol-review assignments. Each assignment involved competing explanations across interacting contracts. The model, effort, tool access, and inputs were the same.

Version A selected two standard reviewers. Version B selected two expert reviewers and gave a concrete reason for each selection. Both produced the required plan. Neither execution refused an expert assignment because of a reviewer count.

No execution used Version B with only the sentence about the expert-reviewer limit removed.

## Proposed interpretation

The successful result proves that the sentence about the lack of an expert-reviewer limit is necessary. It should be copied into every workflow that can launch experts.
